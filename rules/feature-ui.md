# 작은 피쳐 규약 — 단독 채널·폴더링·레이아웃 (정본)

작성 2026-08-31 · 발단 = 캐릭터 빌더(첫 사례·실물 예). 전체 사이트 fesim 옆에
작은 피쳐가 계속 추가된다는 전제의 규약이다. ☠수치·클래스명은 코드가 정본 — 여기는 원칙과 작동 방식만.

## 배포 — 본체와 분리
- 작은 피쳐는 **본체 게이트(기보·룰북)를 태우지 않는다** — 전용 명령(경량 게이트 = 타입 + 웹 테스트)로 낸다.
  실물 = `./dev builder:publish` · 채널 정본 = rules/deploy.md
- 단독 워커 = 같은 빌드 산출물 + 경로 가드(허용목록 밖 404 · 홈 링크 제거) —
  실물 = `wrangler.builder.jsonc` + `workers/builder.js`

## 폴더링 — 피쳐는 한 폴더에
- `apps/web/src/features/<피쳐>/` = 아일랜드(tsx) · 표시층(lib.ts) · 전용 CSS. 라우트(pages)는 조립만
- 공용에 두는 것: 계산·룰 = packages/engine(하나의 답변자) · 테이블→props 사영 = `lib/fe17.ts`(SSG 전용 —
  테이블 로드를 피쳐마다 중복하지 않는다) · 문자열 = `lib/i18n.ts`
- ☠전용 CSS를 global.css에 넣지 않는다(피쳐가 늘면 비대) — `features/<피쳐>/*.css`를 라우트에서 import
- 실물 예 = `apps/web/src/features/builder/`

## 반응형 레이아웃 — 빌더에서 확정된 작동 방식
- **데스크톱**: 표는 내용맞춤 폭 + 페이지 중앙. 안쪽 스크롤 높이는 **플렉스 배분**(main = 100dvh 열, 컨테이너 = flex-1)
  — ☠고정 오프셋 calc 금지(컨트롤 줄바꿈에 깨진다, 실사례)
- **모바일 세로**: **가로와 같은 펼침**(2026-08-31 변경 — 멀티클래스·고유 성장 라인으로 한 화면이 무리) —
  안쪽 스크롤박스 제거, 페이지 스크롤 하나, 표 헤더만 최상단 고정. 밀도 압축은 유지 =
  보조 열(IN.LV) 숨김 · 이름 숨김(포트레이트로 식별). ☠열을 숨길 땐 **헤더·본문 셀을 같이** — 한쪽만 숨기면 열이 어긋난다(실사례)
- **모바일 가로(짧은 세로폭)**: **PC 풀피쳐 + 모두 펼침** — 안쪽 스크롤박스 제거, 페이지 스크롤 하나.
  상단바는 밀려나가고 표 헤더만 최상단(top 0) 고정
- 표 헤더 = 영문 + JetBrains Mono(페이지 한정 로드) · 캡 도달 = 그린 정수(`--cap`) · 강조 = `--gold`
- ☠CSS 함정 2건(실사례): (1) 미디어 블록은 기본 규칙 **뒤**에 — 앞이면 동일 특이성으로 조용히 죽는다
  (2) JSX 빈 줄 스팬의 U+00A0는 치환·검색을 전부 빗나가게 한다 — 빈 줄은 조건부 렌더로 처리

## 체커(토글) 상태 — 전부 브라우저 저장 (2026-08-31 사용자 지시)
- 피쳐의 체커는 **전부 localStorage 부울린**으로 저장한다(키 = `fesim:ui:*`, 실물 = `lib/guestSave.ts`).
- ★기본값은 안전측으로(예: 스포일러 = 숨김) · ☠`"1"/"0"` 외 이물·저장소 예외는 **기본값으로 강하** —
  손상 값이 표시로 새면 조용한 실패다(스포일러가 대표 사례).
- SSG HTML은 기본값으로 굽고 **저장값은 하이드레이션 뒤에 읽는다**(useEffect) — SSR 불일치 방지.
- 부울린이 아닌 UI 상태도 같은 규약으로(예: 엔트리 잠금 = `fesim:ui:entrylocks`,
  스냅샷 객체 배열 JSON `{pid, internal, jid?, star?, iid?, plus?}` — 배열 순서 = 표 상단 순서,
  이물은 원소 단위로 걸러 강하, **저장 시점 = 온오프·드래그 커밋 순간**, 2026-08-31 사용자 지시).
