# 서드파티 라이선스 고지

이 문서는 `apps/web`에 인라인으로 편입한 서드파티 자산(아이콘 SVG 등)의 원 라이선스 고지문을
원문 그대로 보존한다 — 각 라이선스가 요구하는 "고지문 동봉" 의무를 이행하기 위함이다.

## Lucide (ISC License, 일부 아이콘은 MIT)

- **용도**: 엔트리 빌더 공유 버튼 아이콘 — `forward` 아이콘의 SVG path.
  `apps/web/src/features/builder/BuilderIsland.tsx`의 `SHARE` 상수에 인라인으로 편입.
- **출처**: https://github.com/lucide-icons/lucide/blob/main/LICENSE
- **비고**: `forward`는 아래 고지문의 "Feather 유래 아이콘" 목록에 없으므로 최상단 ISC 조항만 적용된다.
