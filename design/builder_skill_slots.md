## 1. 지금의 격자 (코드에서 읽은 실측)

슬롯은 **열 2개(각 `entry-slotw` 9rem) x 밴드 3개 = 6칸**, 전부 `h-7`(28px) 동일 규격.

```
열:        [ 카드 th 244px ]      [skill-col 9rem] [inlv-col 9rem]  [ HP STR MAG DEX SPD LCK DEF RES BLD ]
성장률 행: (직업명)                  빈               빈               성장률 %          <- 체커 조건부
스탯 행:   포트레이트+이름(절대)      개인고유          적성(인라인)      스탯값
반지 행:    "                        커스텀 1         반지 ▾           인연Lv / +N 델타
전투력 행: [클래스 ▾][In.lv ▾]        커스텀 2         무기 ▾           [강화][각인] / 라벨+값 2단 / 무게 2단
```

핵심 관찰 = **전투력 행 한 칸이 라벨 줄 + 값 줄 2단**(pt3 + 20 + 20 + pb10 = 53px)이라
이 행 혼자 다른 밴드(34~41px)의 1.3~1.6배다. 이 2단을 두 밴드로 펴면 **밴드가 4개**가 되고,
늘어난 카드 th 세로가 클래스 행 아래 한 칸을 낳는다 — 적성의 새 자리다.

## 2. 확정 배치 (4밴드 — 스킬 4슬롯 **세로 일렬**)

★2026-09-08 2차 지시: *"개인스킬 밑에 직업스킬로 하는게 낫다 4줄로 재빌드"*.

```
열:          [ 카드 th ]            [skill-col]  [equip-col]  [ HP    STR  MAG  DEX  SPD  LCK  DEF   RES  BLD ]

밴드1 스탯:  ┌ 포트레이트 + 이름     개인고유       (빈)          스탯값 ...
밴드2 반지:  └                      직업고유★      반지 ▾       인연Lv  +2   +0   +4   +4   ...        (델타)
밴드3 슬롯:  [클래스 ▾][In.lv ▾]     커스텀 1       무기 ▾       [강][각] 물공 마공 명중 회피 필살 필살회피  -   무게
밴드4 값:    [적성 ▸ 검 A · 창 B]★    커스텀 2       (빈)          -      34.0 12.0 88.0 41.0 15.0 20.0   -    5
```
★ = 신설. 밴드3 = **슬롯 + 전투력 라벨**, 밴드4 = **슬롯 + 적성 + 전투력 값**.

- 스킬 열 = **4슬롯 세로 일렬**. 위 둘(개인·직업) = 읽기 전용(캐럿 없음 + `.entry-skill-fixed` 배경),
  아래 둘 = 드롭다운. 장비 열은 반지(밴드2)·무기(밴드3) 두 칸만 쓴다.
- ☠**비교 라인(li>0)에는 반지 행이 없다** = 밴드2가 없다. 그래서 비교 라인의 직업 고유는
  **그 라인 밴드1 skill-col**에 세운다(안 그러면 라인 2 이상의 직업 스킬이 조용히 사라진다).
- 적성은 h-7 슬롯이 아니라 인라인 아이콘 줄이라 격자를 안 먹는다 — 카드 th 폭 전체(232px)를
  혼자 쓰므로 랭크가 잘리지 않는다(9rem에서 무기군 4종이면 빠듯하다).
- **폭 불변** — 헤드리스 실측 1341px(개편 전후 동일, 열이 안 늘었다).
  세로는 전투력 행 53 -> 밴드3 34 + 밴드4 30 = 64px, **캐릭터당 +11px**(적성 줄이 카드에 새로 서는 값).
- 카드 th 절대배치: `entry-classrow` bottom 33(= 밴드4 30 + 밴드3 상단 패딩 3) ·
  `.entry-aptrow` bottom 10(값 행 하단 패딩과 같은 자리) · `entry-wrap` bottom 67(= 33 + 28 + 6).
- ★비교 라인(멀티클래스)의 적성은 **그 라인의 값 행(밴드4) 장비 열**이 맡는다 — 카드 th의 적성 줄은
  라인 0만 덮으므로, 안 그러면 라인 2 이상의 적성이 조용히 사라진다(실측 확인: 소드마스터 검S /
  세이지 마도서S·검B가 라인별로 따로 선다).

### 기각한 대안 (이력)
- 스킬 열 1개 추가(2x2 블록) — 표 폭 1341 -> 1485px, 페이지 가로 스크롤 증가.
- 스탯 밴드 안 2단 스택 — 세로 +26px, 전투력 2단은 그대로 남아 밴드 비대칭이 유지된다.
- 강화·각인을 스킬 열로 이사 — ☠세로폰은 `.skill-col`을 걷으므로 칩이 조용히 사라진다(결손).

## 3. 배치와 무관하게 확정된 것

- **데이터**: 직업 고유 스킬 = `jobs.json`의 `LearningSkill`(= 兵種스킬). 목표 직업 59종 중 **35종** 보유(테이블 전체로는 40종 — 적 전용 변형 등 목록 밖 5종 포함),
  **기본직(Rank 0 / MaxLevel 20)은 없음** -> 빈 슬롯(점선·흐림)이 정상이다.
  사영 = `BuilderJobProp.jobSkill?: EmblemSkillProp` 한 필드(`fe17.ts` 직업 루프, 개인고유와 같은 방식).
- **저장·공유 스키마 무변경**: `EntryLock.skills`는 커스텀 2칸(`[string, string]`) 그대로.
  개인고유는 pid 파생, 직업고유는 jid 파생 — 저장할 것이 없다.
- **카드 이미지 내보내기**: 한 열 안에서 칩을 쌓는 모델이라 `ownSkill` 다음 `jobSkill` 한 줄 추가로 끝.
- **HTML 공유(share.ts)**: 캡션 1종 추가. 아이콘은 안 붙인다(skills 자산 파일명이 일본어 — 기존 규약).
- **로케일**: `personalSkill`과 같은 층에 `jobSkill` 라벨 3종(ko/en/ja) — UI 문자열이라 전 로케일 필수.

## 4. 결정 (2026-09-08 — "로컬만 착수" 승인 시 권장안대로 적용, 사용자 확인 대기)

### Q1. 밴드4의 스킬 칸 = 비움 (장비 칸은 비교 라인 적성이 쓴다)
- 배경: 값 행이라 슬롯이 없어도 자연스럽다. 다만 무기(밴드3) 바로 아래가 비므로
  **특효(効効) 칩**을 그 자리에 놓을 수 있다 — 카드 이미지 내보내기에는 이미 있고 표에는 없는 정보다.
- 선택지: (1) 비운다 (2) equip-col에 특효 칩 (3) equip-col에 무기 스펙 요약(위력·명중·필살)
- 권장: **(1) 비운다** — 이번 작업은 슬롯 격자 개편이고, 특효 표기는 정보량 결정이라 축이 다르다.
  하고 싶으면 별건으로 올린다(그때 세로폰 처우도 같이 정한다).
- 안 정하면 막히는 것: 밴드4 셀의 패딩·정렬(비우면 값 행 높이만, 칩이 오면 h-7 기준).

### Q2. 세로폰 적성 줄 = 숨김
- 배경: 지금 적성은 `inlv-col`에 있어 세로폰에서 열째 숨겨진다(밀도 우선). 카드 th로 옮기면
  **세로폰에도 보이게 된다** — 카드 th는 세로폰에 살아 있다.
- 선택지: (1) 세로폰도 표시(카드가 두 줄이 된다) (2) 세로폰은 `.entry-aptrow` 숨김(현행 밀도 유지)
- 권장: **(2)** — 세로폰 규약이 "전 스탯 무스크롤 한 화면"이고 이름·스킬 열까지 걷는 마당이다.
- 안 정하면 막히는 것: `builder.css` 세로폰 블록 한 줄. 되돌리기 쉬우니 비차단.

### Q3. 개인·직업 고유 = **표시 전용** / 계산은 계승(커스텀) 2칸만 (2026-09-08 확정)
> *"발동은 미발동 개인스킬도 마찬가지"* · *"스킬이 무엇인지 보여주기 위함이다"* ·
> *"단 계승스킬의 경우 스탯과 전투력에 영향을 주는 패시브가 많으므로 반영해야한다"*

- 슬롯 4칸의 역할이 갈린다: **개인 고유·직업 고유 = 무엇을 가졌는지 보여주는 자리**(표기 단면만
  사영 — `EmblemSkillProp`, `SkillRow` 미동봉) / **계승 2칸 = 계산에 드는 층**
  (`InheritSkillProp.row` → `skillStatDelta` + `combatOf(.., skills)`).
- **레벨 게이트 없음** — 그 직업이면 표시된다(내부 레벨 0이어도).
- ☠경계는 테스트가 지킨다(`직업 고유는 표시 전용 — 전투력은 계승 2칸만 반영한다`).
  슬롯이 나란히 서 있어 나중에 전부 엔진에 넣고 싶어지는 자리라, 넣으면 표시값이 조용히 움직인다.
- 근거 실측: 목표 직업 35종의 직업 스킬은 어차피 **정적 표에서 값이 안 움직인다**(전수 스캔 0건 —
  전부 전투 컨텍스트 조건부이고 `命中率`·`必殺率`은 `命中値`·`必殺値` 식 밖). 배선해도 얻는 것이 없었다.

> 이력: 같은 날 한때 직업 고유를 엔진에 물렸다가(6d65278) 위 지시로 되돌렸다. 되돌림으로 인한
> 수치 변화는 없다(위 실측).

### Q4. 읽기 전용 2칸 = 배경 한 단계 낮춤(`.entry-skill-fixed`)
- 배경: 커스텀 2칸은 드롭다운(▾), 고유 2칸은 고정 칩인데 지금은 캐럿만 없고 테두리·배경이 같다.
  밴드1에 둘이 나란히 서면 "왜 이건 안 눌리지"가 생긴다.
- 선택지: (1) 현행 유지 (2) 테두리 없는 평면 칩 (3) 배경만 한 단계 어둡게(규격 유지)
- 권장: **(3)**.
- 안 정하면 막히는 것: 없음(구현 중 조정 가능).
