## 2. 편집기 (제작 모드) — 2층 구조

- **수순층(이미 절반 존재)**: 현 플레이 모드가 기록(.eph 자동)을 수행. 추가 = **플레이 언두**(§0 M3 이월 해소) ·
  수순 되감아 이어 만들기(리플레이 커서에서 "여기부터 다시")
- **세팅층(신규)**: 초기 국면 편집 — 유닛 배치 이동·제거, 장비 변경, 레벨, 스킬·엠블렘 장착
- **setup 스키마**: `EphemerisFile.setup`(현재 "M4" 주석 자리) = dispos 기본 대비 **diff만** 기록.
  타입이 정본(shared/ephemeris.ts 확장), 검증은 파서 뼈대 + 엔진 초기화가 실판정
- 구현 노트: 편집 UI = 별도 청크(제작 경로 — 열람 예산 0바이트 불변) · **Immer 도입**(§0 미룸 해소 조건 = 편집기 중첩 갱신) ·
  엔진 계약 불변(초기 국면 구성만 달라진다)

## 3. 소셜 로그인 — better-auth + Workers + D1

- 프로바이더: **Google·Discord 먼저**(2026-08-15 결정), X·Kakao·Naver 순차
- workers/api 확장: auth 라우트 + D1 바인딩(better-auth 스키마 테이블 + `strategies` 테이블)
- 게이트 경계(결정 그대로): **서버 쓰기(발급·아카이빙)만 로그인** — 열람·제작·로컬 보관 무계정
- 세션: better-auth 쿠키 — /s/ 열람 경로는 auth 미들웨어를 타지 않는다(성능 게이트 보호)

## 4. 발급 API + claim

- `POST /api/links` (로그인 필수): .eph 본문 → 뼈대 검증(parseEphemeris) → id 생성 → KV put → `/s/{id}` 반환
- id: 짧은 무작위(충돌 시 재시도). 자릿수·알파벳은 미결 Q5
- 어뷰즈 방어(로그인 게이트 전제): 본문 크기 상한 + 사용자당 발급 상한 — 수치는 미결 Q5
- claim: 로그인 직후 localStorage 전략 전부 D1 자동 귀속(수동 단계 없음 — 결정 2026-08-16) · 이후 로컬+서버 이중 저장

## 5. 전략 카드 + 플랫폼 프리셋

- 카드 v1 방식 = 미결 Q4: (a) 클라이언트 캡처(보드 DOM → canvas → PNG 1200×630, R2 업로드) vs
  (b) Workers+Satori 서버 생성 vs (c) M4에선 정적 og:image로 미룸
- 프리셋(계획서 4-3): 데스크톱 = ClipboardItem 다중 MIME, 모바일 = navigator.share · `?src=` 유입 태그
- R2 편입은 카드 방식이 (a)/(b)일 때만

## 6. 기보 코드 UX + 신고 버튼

- 가져오기: 붙여넣기 → parseEphemeris + 엔진 verify → **행동 단위 오류 메시지 표시**(LLM 왕복 검증기의 골격)
- 신고 버튼 최소형: 현재 .eph + 국면 주소 클립보드 복사 + GitHub 이슈 템플릿 링크(무서버)

## 7. 미결 (질문 게이트 — 승인 전 결정 필요)

- **Q1 단계 편성**: §1 순서(편집기 선행) 승인? 대안 = 백엔드(로그인·발급) 선행.
  권장 = 편집기 선행(발급 소비자 부재 문제의 재발 방지). 미정 시 = 착수 불가
- **Q2 편집기 v1 범위**: (a) 배치·장비만 (b) +레벨·스킬 (c) 풀빌드(+엠블렘·성장 재계산).
  권장 = (b) — LTC 문법의 최소 요구(레벨·장비)가 담기고, 엠블렘은 엔게이지 미룸과 정합.
  미정 시 = setup 스키마 폭이 못 굳는다
- **Q3 언두 편입**: 수순 언두를 4-1에 포함? 권장 = 포함(제작 경험의 기본기, 미룸 해소 조건 충족).
  미정 시 = 4-1 범위 불확정
- **Q4 전략 카드 v1 방식**: §5의 (a)/(b)/(c). 권장 = (a) 클라 캡처(비용 0·고품질, 계획서 원안).
  미정 시 = R2 편입 여부가 못 굳는다
- **Q5 발급 정책 수치**: id 자릿수·본문 상한·사용자당 상한. 권장 = 8자 base58 · 256KB · 일 50건(보수적 시작, 실측 후 완화).
  미정 시 = API 구현 착수 불가는 아님(상수라 나중 조정 가능) — 저우선
- **Q6 D1 strategies 스키마 폭**: 소유·수정·비공개 플래그까지 v1? 권장 = 소유+비공개 최소셋.
  미정 시 = claim 구현이 못 굳는다
